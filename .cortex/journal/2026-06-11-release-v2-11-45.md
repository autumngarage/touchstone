## What shipped

- Guidance now treats the PR as the review/check coordination surface: the driving CLI opens or updates the PR, watches comments and status, addresses actionable feedback with commits, and merges only after required reviews/checks approve.
- `scripts/merge-pr.sh` now fails closed when GitHub reports a draft PR, active requested-changes review decision, unresolved review threads, or an inability to inspect PR feedback metadata.
- The merge helper checks PR-visible feedback before Conductor review and again after review on the exact reviewed head before squash merge.
- Verified deployment through the full deterministic merge-gate preflight, clean Conductor review, successful GitHub release workflow, and local `brew update && brew upgrade touchstone`.
