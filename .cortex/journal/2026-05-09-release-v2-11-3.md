## What shipped

- Fix the merge gate so Conductor runs in `fix` mode instead of review-only mode.
- If Conductor changes the PR head during the merge gate, rerun deterministic checks, push the reviewed head back to the PR branch, wait for GitHub to see that exact head, then merge by SHA.
- Verified the release through the fast shell suite, slow bootstrap probe, GitHub release workflow, and local `brew upgrade touchstone`.
